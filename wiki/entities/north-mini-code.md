# North Mini Code

**Type**: concept  
**Tags**: #entity

## Overview

**North Mini Code** (**North-Mini-Code-1.0**) is Cohere's first open-weight model for developers (June 2026): a 30B-total / 3B-active sparse MoE agentic coding model released under Apache 2.0 on Hugging Face, with API and Model Vault hosting.

- [[Introducing North Mini Code]] — launch announcement and technical post-training details (architecture, multi-harness SFT, async CISPO RLVR).

## Notes

- Optimized for agentic software engineering, terminal tasks, and code generation; trained for cross-harness robustness (SWE-Agent, mini-SWE-agent, OpenCode, Terminus-2).
- Artificial Analysis Coding Index 33.4; minimum stated hardware 1× H100 @ FP8.
- First model in Cohere's new open developer model family.
