# Intel

**Type**: org

## Overview

Intel's AI Software Group publishes applied research on efficient reasoning and agentic tooling, including DeepMath, a lightweight math reasoning agent that offloads deterministic computation to a sandboxed Python executor instead of doing arithmetic in verbose chain-of-thought text.

## Appearances

- [[DeepMath: A Lightweight Math Reasoning Agent With Smolagents]] — Qwen3-4B Thinking fine-tuned with GRPO to call short Python snippets mid-reasoning via smolagents, cutting output length by up to 66% while improving accuracy.
