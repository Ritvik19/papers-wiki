# Arm

**Type**: org
**Tags**: #entity

## Overview

Arm is a semiconductor and software design company best known for its mobile CPU/GPU architectures. It develops Neural Accelerators (NX) for mobile GPUs and Neural Super Sampling (NSS), a machine-learning real-time upscaling model designed to run on that hardware for mobile gaming and XR.
