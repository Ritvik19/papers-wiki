# OpenClaw

**Type**: tool  
**Tags**: #entity

## Overview

**OpenClaw** is a local, general-purpose agent platform that can perform coding among other workloads. [[Components of A Coding Agent]] contrasts it with specialized coding harnesses: OpenClaw uses workspace instruction files (`AGENTS.md`, `SOUL.md`, `TOOLS.md`), JSONL session files with transcript compaction, and subagent spawning, but optimizes for long-lived agents across chats, channels, and workspaces rather than repo-centric terminal coding assistants.
