# Pedro Felzenszwalb

**Type**: person  
**Tags**: #entity

## Overview

Pedro Felzenszwalb is a computer vision researcher known for **graph-based image segmentation** (with Daniel Huttenlocher, IJCV 2004) and the **Deformable Parts Model** for object detection (with Girshick, McAllester, Ramanan, PAMI 2010).

## Appearances

- [[Object Detection for Dummies Part 1]] — Felzenszwalb–Huttenlocher segmentation; \(Int\), \(Dif\), \(MInt\) merge predicate; `skimage` demo.
- [[Object Detection for Dummies Part 2]] — DPM root/part filters and latent SVM matching.

## Impact on detection pipeline

| Work | Role in later systems |
|------|----------------------|
| Segmentation (2004) | Initial regions for [[Selective Search]] |
| DPM (2010) | State-of-art pre-CNN detection; HOG features |
| DPM as CNN (Girshick 2015) | Shows equivalence to conv inference |
