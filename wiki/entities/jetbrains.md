# JetBrains

**Type**: org  
**Tags**: #entity

## Overview

JetBrains is a software tools company (IntelliJ IDEA, PyCharm, etc.) that builds AI-assisted developer products. Its AI lab released the **Mellum** open-weight code model family: dense 4B completion models for IDE latency and 12B MoE agentic coding successors.

## Appearances

- [[Papers Explained 582: Mellum]] — 4B FIM code completion trained for in-editor use.
- [[Papers Explained 583: Mellum 2]] — 12B/2.5B-active MoE coding agent with tool use and RLVR.

## Notes

Mellum models use internal **Code Engine** for semantic FIM segments and project-context collection (IoU, path distance, RAG).
