# Pierre Sermanet

**Type**: person  
**Tags**: #entity

## Overview

Pierre Sermanet is a co-author of **Overfeat** (2013), an integrated CNN for simultaneous **classification, localization, and detection** via sliding windows and class-specific bounding-box regressors on shared conv features.

## Appearances

- [[Object Detection for Dummies Part 2]] — two-stage Overfeat training (ImageNet cls then L2 box regression).

## Overfeat in context

Predates [[R-CNN]]'s region pipeline but anticipates:

- Shared convolutional trunk for multiple tasks
- Dense sliding-window evaluation
- Per-class spatial regressors

Later unified in [[Fast R-CNN]] / [[Faster R-CNN]] multi-task heads.
