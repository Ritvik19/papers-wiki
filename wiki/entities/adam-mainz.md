# Adam Mainz

**Type**: person  
**Tags**: #entity

## Overview

AI and machine learning performance engineer (ex-Meta, currently working on PyTorch TPU at Google). Mainz writes pedagogical technical articles explaining GPU systems, PyTorch internals, and compiler optimizations under the handle @MainzOnX.

## Appearances

- [[What Even Is a Kernel?]] — author of the visual guide to GPU kernel execution, CPU launches, eager-mode memory traffic, and `torch.compile` fusion.
- [[Two Speeds of a GPU]] — author of the explainer on GPU compute vs memory bandwidth ceilings, arithmetic intensity, and the Roofline Model.

## Notes

- Known for first-principles hardware mental models (e.g., the chef-and-runner kitchen analogy for memory vs compute bounds).
- Focuses on bridging high-level PyTorch tensor code to low-level hardware counters and profiler outputs.
