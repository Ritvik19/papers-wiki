# Parameter Sharing

**Type**: concept  
**Tags**: #concept

## Overview

Parameter sharing (weight tying) reuses the same parameters across multiple parts of a model—e.g. convolutional filters across spatial locations or tied input–output embeddings—reducing parameter count and encoding invariances.
