# Cyber Verification Program

**Type**: concept  
**Tags**: #concept

## Overview

Anthropic's **Cyber Verification Program** is an opt-in enrollment path for organizations doing legitimate cybersecurity research. Verified participants can run Claude models with reduced cyber guardrails without submitting a new application for each model release.

## Appearances

- [[Claude Models]] — Sonnet 5 launch (June 2026); Fable 5.1 / Mythos 5.1 (Sep 2026) adds upcoming Mythos-class CVP access.
- [[Anthropic]] — safety and deployment policy for frontier cyber capability.

## Notes

- Sonnet 5 ships with cyber safeguards enabled by default, in the same class as Opus 4.7 and Opus 4.8 but less strict than [[Claude Fable Safeguards]] on Fable 5.
- The program sits alongside Anthropic's broader [[Responsible Scaling Policy]] framework and trusted-access channels like [[Project Glasswing]] for Mythos-class cyber work.
- Sonnet 5 is weaker than Opus/Mythos on dangerous cyber evaluations; Anthropic reports it never produced a working Firefox exploit in Mozilla's test.
