# Nemotron 3 Nano Omni

**Type**: concept  
**Tags**: #concept #entity

## Overview
A 3.2B native omni-modal foundation model by NVIDIA supporting unified processing of text, images, video, and full-duplex speech within a single compact architecture.

- [[Papers Explained 590: Nemotron 3 Nano Omni]] — technical report (arXiv:2604.24954).
- [[Introducing NVIDIA Nemotron 3 Nano Omni: Long-Context Multimodal Intelligence for Documents, Audio and Video Agents]] — official release blog.

## Notes
- Features integrated speech codecs, dynamic vision tiling, and 128k context support for edge deployment.
