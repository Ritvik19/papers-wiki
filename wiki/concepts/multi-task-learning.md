# Multi-Task Learning

**Type**: concept  
**Tags**: #concept

## Overview

Multi-task learning trains one model on several related tasks simultaneously, sharing representations so tasks regularize each other. Hard sharing uses common layers; soft sharing uses linked parameters or penalties.
