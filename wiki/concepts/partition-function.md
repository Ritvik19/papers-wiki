# Partition Function

**Type**: concept  
**Tags**: #concept

## Overview

The partition function Z normalizes an energy-based distribution so probabilities sum (or integrate) to one. Computing or estimating Z is intractable for many undirected models, centralizing difficulty in generative learning.

## Appearances

- [[Deep Learning]] — Chapter 18 is devoted to confronting the partition function (contrastive divergence, pseudolikelihood, score matching, NCE).

## Notes

Modern implicit models (GANs) avoid explicit Z; diffusion models use a different generative parameterization. The book's treatment explains why classical Boltzmann learning is hard.
