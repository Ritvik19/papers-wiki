# SelfCheckGPT

**Type**: concept  
**Tags**: #concept

## Overview

SelfCheckGPT (Manakul et al. 2023) detects hallucinations in **black-box LLMs** by checking factual consistency across multiple stochastic samples from the same prompt. The core intuition: if a model "knows" a fact, it will consistently reproduce it across random samples; if a fact is fabricated, the model will generate different (inconsistent) versions across samples.

## Motivation

Grey-box hallucination detection (e.g., computing token-level log-probabilities) requires internal model access. SelfCheckGPT requires only **generation-level black-box access** and **no external knowledge base** — making it universally applicable to any hosted or API-only LLM.

## Method

```
Input: a prompt P
Step 1: Generate primary response R₀ at temperature > 0
Step 2: Generate N additional stochastic samples R₁, ..., Rₙ from the same prompt P
Step 3: For each sentence s in R₀:
    Measure consistency between s and each Rᵢ using a scoring function
Step 4: Sentences with low consistency scores are flagged as likely hallucinations
```

### Consistency Scoring Functions

| Method | Description | Notes |
|--------|-------------|-------|
| **BERTScore** | Semantic token-level similarity between sentence s and each sample Rᵢ | Relatively fast |
| **NLI** | Natural language inference: does Rᵢ entail / contradict / are neutral to s? | Computationally heavier |
| **Prompting** | Ask the LLM "Is the following statement consistent with [sample]? Yes/No" | Best performing |
| **n-gram** | Simple n-gram overlap between s and samples | Baseline |

**Best performer**: SelfCheckGPT with **LLM prompting** on GPT-3 generated WikiBio passages.

## Key Properties

| Property | Value |
|----------|-------|
| External knowledge base required? | ❌ No |
| Model internals (logprobs) required? | ❌ No |
| Works on black-box APIs? | ✅ Yes |
| Sensitive to systematic errors? | ⚠️ Yes (consistent false beliefs not flagged) |

## Failure Mode

If a model has a **systematic, consistent false belief** baked in from pre-training (e.g., consistently wrong about a specific historical date), SelfCheckGPT will **not** flag it — the error is internally consistent across samples. It is most effective for catching *stochastic* confabulation of details the model doesn't know.

## Tested On

- **WikiBio** passages generated by GPT-3 (biographies about Wikipedia subjects).
- SelfCheckGPT with prompting showed strong correlation with human-annotated factuality labels.

## Appearances

- [[Extrinsic Hallucinations in LLMs]] — presented as the canonical sampling-based, zero-resource hallucination detection method.

## Notes

SelfCheckGPT is complementary to retrieval-based methods (FActScore, SAFE):
- **SelfCheckGPT**: no reference needed; catches stochastic confabulation; misses systematic errors.
- **FActScore / SAFE**: needs a knowledge base or search access; catches both stochastic and systematic errors if evidence exists.

The compute cost scales linearly with the number of samples N. In practice, N=5–20 samples balances detection quality with cost.
