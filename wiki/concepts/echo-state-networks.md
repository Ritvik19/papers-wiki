# Echo State Networks

**Type**: concept  
**Tags**: #concept

## Overview

Echo state networks (ESNs) use a large fixed random recurrent reservoir with only readout weights trained. The reservoir nonlinearly expands input history so linear readouts can solve temporal tasks efficiently.
