# Claude Code

**Type**: concept  
**Tags**: #concept

## Overview

**Claude Code** is Anthropic's agentic coding product: a terminal-first collaborator that searches and reads code, edits files, runs tests, commits to GitHub, and uses CLI tools—with optional IDE extensions (VS Code, JetBrains), GitHub Actions integration, and desktop parallel sessions. Introduced as a research preview with **Claude 3.7 Sonnet** (Feb 2025) and reached **general availability** with **Claude 4** (May 2025).

## Notes

- Early internal testing: tasks taking 45+ minutes completed in one pass.
- **Claude Agent SDK** (Sep 2025) exposes the same infrastructure for non-coding agents.
- **Plan Mode** (Opus 4.5+): clarifying questions → editable plan.md → execution.
- **Dynamic workflows** (Opus 4.8): hundreds of parallel subagents for codebase-scale migrations.
