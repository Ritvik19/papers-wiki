# Computer Use

**Type**: concept  
**Tags**: #concept

## Overview

**Computer use** is the capability for an AI model to operate a computer through the same interface a human would—viewing screens, moving a cursor, clicking, typing, and navigating applications—rather than calling purpose-built APIs. Anthropic introduced general-purpose computer use in public beta with the upgraded **Claude 3.5 Sonnet** in October 2024 ([[Claude Models]]), scoring **14.9%** on OSWorld (screenshot-only) and **22.0%** with extended steps—the first frontier model to offer this in public beta.

## Appearances

- [[Claude Models]] — Oct 2024 launch; OSWorld gains through Sonnet 4.5 (61.4%), Sonnet 4.6, Opus 4.7/4.8.
- [[Introducing Gemini 3.6 Flash, 3.5 Flash-Lite, and 3.5 Flash Cyber]] — Computer use as a built-in client-side tool in Gemini API and Enterprise; OSWorld-Verified 83.0% (3.6 Flash) and 74.0% (3.5 Flash-Lite).
- [[Agentic AI]] — Computer use as a general agent interface for legacy software without APIs.
- [[Vision Language Models]] — Screenshot understanding and visual grounding for GUI control.

## Notes

- Early releases were experimental; Anthropic warned about scrolling/dragging limitations and prompt-injection risks from malicious web content.
- OSWorld-Verified became the standard benchmark; scores improved from ~22% (Oct 2024) to 61%+ (Sonnet 4.5, Sep 2025) over ~11 months.
- Product integrations include Claude for Chrome, Excel, and PowerPoint.
