# Singular Value Decomposition

**Type**: concept  
**Tags**: #concept

## Overview

Singular value decomposition (SVD) factorizes a matrix into orthogonal rotations and a diagonal matrix of singular values. It generalizes eigendecomposition to non-square matrices and underpins PCA, low-rank approximation, and many compression methods.
