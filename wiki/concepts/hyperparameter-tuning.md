# Hyperparameter Tuning

**Type**: concept  
**Tags**: #concept

## Overview

Hyperparameter tuning selects settings not learned from gradients—learning rate, batch size, network depth, regularization strength—using validation performance, grid/random search, or automated protocols.

## Appearances

- [[Deep Learning]] — Chapter 11 (especially 11.4–11.5) covers selection, debugging, and practical methodology for deep learning experiments.

## Notes

Expensive for large models; modern practice uses scaling laws, few-shot transfer, and heuristic recipes (e.g. "Chinchilla-optimal" tokens) alongside manual tuning.
