# Value-Order Correlation

**Type**: concept  
**Tags**: #concept

## Overview
A metric defined as the Spearman rank correlation between the step index of an agent trajectory and the continuous verification score assigned to that prefix, quantifying how reliably a verifier tracks monotonic task progress.
