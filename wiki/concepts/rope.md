# RoPE

**Type**: concept  
**Tags**: #concept

## Overview
Rotary Position Embedding (Su et al., 2021); a positional encoding method that rotates Query and Key representations in 2D complex subspaces by angle $m\theta$, naturally encoding relative distance $m-n$ into inner-product self-attention scores.

## Notes
- Universal standard in modern LLMs (LLaMA, Qwen, Mistral, Gemma, DeepSeek).
