# MAP Inference

**Type**: concept  
**Tags**: #concept

## Overview

Maximum a posteriori (MAP) inference finds the most probable assignment of latent variables given observations and a prior, combining likelihood with prior penalties. In sparse coding, MAP inference yields sparse activations.
