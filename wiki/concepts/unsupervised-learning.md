# Unsupervised Learning

**Type**: concept  
**Tags**: #concept

## Overview

Unsupervised learning discovers structure in unlabeled data—clusters, manifolds, generative factors—without target labels. It includes density estimation, [[Autoencoders]], clustering, and pretraining representations for downstream tasks.
