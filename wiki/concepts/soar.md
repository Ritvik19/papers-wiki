# SOAR

**Type**: concept  
**Tags**: #concept

## Overview
Self-Optimization via Asymmetric RL (SOAR); an asymmetric teacher-student reinforcement learning framework where an outer-loop teacher generates difficulty-calibrated reasoning problems to maximize student learning progress in an inner RL loop.

## Appearances
- [[Papers Explained: Self-Optimization via Asymmetric RL (SOAR)]] — introduced by Wang et al. (2026).

## Notes
- Bridges asymmetric self-play with verifiable reward RL.
