Papers Explained 548: CHIMERA

CHIMERA is a compact synthetic reasoning dataset comprising 9K samples designed to support generalizable reasoning across domains. It is constructed with three key properties:

It provides rich, long CoT reasoning trajectories synthesized by state-of-the-art reasoning models;
It has broad and structured coverage, spanning 8 major scientific disciplines and over 1K fine-grained topics organized via a model-generated hierarchical taxonomy
It employs a fully automated, scalable evaluation pipeline that uses strong reasoning models to cross-validate both problem validity and answer correctness, removing the reliance on human annotations.

The dataset and models are available on HuggingFace.

Method
Data synthesis pipeline overview.
The pipeline comprises:

Subject Expansion: given a small set of high-level subjects (e.g., math, physics, etc.), gpt-5 is leveraged to list as many topics under the subject as possible, which leads to a comprehensive topic hierarchy for each subject.
Problem Generation: given a specific topic, gpt-5 is further used to propose a clear, self-contained and easy-to-verify problem along with the corresponding answer, this process can be repeated several times to synthesize multiple examples for one topic.
Solution Synthesis: for each problem, a detailed reasoning trajectory is generated with Qwen3–235B-A22B-Thinking-2507.

All the stages are separate and intermediate artifacts are saved, enabling subsequent dataset filtering and curation.

Subject Expansion

First, a small set of high-level subjects S that are broad and abstract, such as mathematics, physics, and computer science, are collected. These subjects are intentionally coarse-grained to minimize human design choices and to encourage wide domain coverage. For each subject s, gpt-5 is prompted to generate a comprehensive list of fine-grained topics Ts that span the conceptual space of the subject. To cover the most foundational concepts of mathematics, which has too many subfields, multiple samples are taken. After the expansion, deduplication is conducted to ensure each topic is unique. The resulting topic lists form a hierarchical taxonomy that serves as the backbone of the dataset.

Problem Generation

Given the expanded set of topics, reasoning problems are generated by prompting gpt-5 to produce one problem and the corresponding answer (q, a) for each topic t. Each problem is required to satisfy the following criteria:

Solvability and Difficulty: The problem must be solvable by an expert at a PhD level and is not an open research problem.
Self-contained: All necessary information must be included in the problem statement.
Unambiguous and verifiable answer: The problem should admit a clear and unique answer. The correctness of the answer should be easy to verify.

To ensure the reliability of synthesized data, cross-model verification is performed after problem generation. Specifically, two independent LLMs, gpt-5 and o4-mini, are employed as verifiers V to assess both problem validity and answer correctness. Each verifier checks whether

The problem is well-posed and unambiguous
The provided answer correctly solves the problem

A problem is retained only if it passes verification by both models.

Solution Synthesis

A strong open reasoning-intensive model R is applied to each problem q created in a previous stage. A detailed reasoning trajectory r is regenerated for each problem q. Qwen3–235B-A22B-Thinking-2507 is employed to produce the step-by-step reasoning trajectories. Each trajectory r is then compared with the original answer a to the problem q and labeled for correctness y ∈{0, 1}. Reasoning trajectories that lead to correct final answers can be used for supervised fine-tuning. The other problems without correct reasoning trajectories are kept as problem-answer-only instances and can be used for reinforcement learning, where only the final answer is required for training.

Experimental Setup

Starting from Qwen3–4B-Thinking-2507 as the base model, supervised fine-tuning is performed on problems whose reasoning trajectories are verified as correct during solution synthesis. Further, reinforcement learning with CISPO is applied for one Epoch, and 8 rollouts per prompt, starting from the SFT model. RL is conducted on a mixture of (i) the SFT training set and (ii) a curated subset of synthesized problems that were unsolved during solution synthesis but can be solved by the SFT model within 8 trials. Since the dataset contains free-form answers rather than multiple-choice outputs, LLM-based reward evaluation is relied upon to provide reliable reward signals. o4-mini is used as the reward model to score generated rollouts during RL.

Benchmarks: GPQA-Diamond (GPQA-D), AIME24, AIME25, AIME26, HMMT25 and HLE (text-only problems)

Baselines:

The base model Qwen3–4B-Thinking-2507 without additional fine-tuning
The base model fine-tuned on OpenScience, and
The base model fine-tuned on CHIMERA.

Evaluation
Main results on reasoning benchmarks.
Fine-tuning on CHIMERA consistently improves pass@1 over the base model on multiple benchmarks.
The 4B CHIMERA-fine-tuned model matches or surpasses 8B–70B baselines on almost all benchmarks and approaches the performance of much larger models (e.g., DeepSeek-R1, Qwen3–235B-A22B).
Fine-tuning on OpenScience leads to worse downstream performance than the base model across benchmarks.
Hypothesized reason: OpenScience’s multiple-choice format encourages shortcut strategies (e.g., elimination) rather than explicit multi-step, free-form reasoning, making it less effective for improving general reasoning.
