# GPT‑5.4 Thinking System Card

GPT‑5.4 Thinking is the latest reasoning model in the GPT‑5 series. The comprehensive safety mitigation approach for this model is similar to previous models in this series, but GPT‑5.4 Thinking is the first general-purpose model to implement mitigations for **High capability in Cybersecurity**. The approach to cyber safety builds on the latest approaches implemented for GPT‑5.3‑Codex, in ChatGPT and the API.

Referred to in this card as `gpt-5.4-thinking`. Note there is no model named GPT‑5.3 Thinking, so the main baseline is GPT‑5.2 Thinking.
