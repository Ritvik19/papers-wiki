# Gemma 4 Assistant

**Source**: Hugging Face Transformers documentation  
**URL**: https://huggingface.co/docs/transformers/main/en/model_doc/gemma4_assistant

See `raw/gemma4-assistant-docs/full-article.md` for canonical HTML.

Gemma4AssistantForCausalLM enables MTP speculative decoding with Gemma 4 IT models. Key API: shared_kv_states, cross-attention, constant position_ids, concat(embedding, hidden_states) inputs, Gemma4AssistantConfig centroid parameters.
