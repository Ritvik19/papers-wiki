# Introducing Claude Sonnet 5

Source: https://www.anthropic.com/news/claude-sonnet-5

Claude Sonnet 5 is built to be the most agentic Sonnet model yet. It can make plans, use tools like browsers and terminals, and run autonomously at a level that, just a few months ago, required larger and more expensive models.

Sonnet 5 narrows the gap with Opus 4.8 at lower prices. It is a substantial improvement over Sonnet 4.6 on reasoning, tool use, coding, and knowledge work.

Pricing: $2/$10 per million tokens through August 31, 2026, then $3/$15. API id: `claude-sonnet-5`. Default model on Free and Pro plans.

Key safety notes: lower hallucination and sycophancy than Sonnet 4.6; cyber safeguards enabled by default; part of Cyber Verification Program for reduced guardrails on enrolled orgs.

Tokenizer update may map the same input to 1.0-1.35x more tokens than Sonnet 4.6; introductory pricing is set to keep the transition roughly cost-neutral.
