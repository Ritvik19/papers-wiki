Gym-Anything

From Papers wiki, the style-inspired explainer · paper: 2604.06126

Overview

Gym-Anything is a framework for turning arbitrary software into interactive computer-use agent environments, together with a multi-agent pipeline that builds, audits, and scales those environments into the benchmark-and-training collection CUA-World. The paper argues that faithful software environments—with real data, long-horizon tasks, and reliable verification—are a major bottleneck for realistic evaluation, not agent capability alone.

Environment construction is reframed as an agentic problem: a small specification (install, configure, and task-setup scripts plus a configuration file) is written and debugged by a creation agent, which produces evidence such as screenshots and logs; an independent audit agent verifies whether the software reached the intended state—closer to iterative coding and auditing than one-off benchmark curation.

Pipeline & mechanisms

GDP-grounded selection → Creation + audit loop → Task scaling → Checklist evaluation

Software selection

Occupations are mapped to software categories using U.S. economic data, web-assisted discovery, and filtering for sandboxable GUI applications. The wiki summarizes this as narrowing toward roughly 200 built environments from 894 occupations and about 16,600 products—aiming for economically meaningful breadth rather than narrow consumer demos.

Task scaling

The wiki describes a propose-and-amplify task pipeline that separates expensive seed-task creation from cheaper large-scale task generation so breadth stays feasible.

Verification

A checklist-based vision-language model verifier uses privileged information extracted from setup scripts. The paper also reports distilling successful trajectories into a 2B vision-language model that beats models roughly twice its size, and a test-time audit pass.

CUA-World (output benchmark)

CUA-World packages more than 10,000 tasks across 200 software applications and three operating systems (Linux, Windows, Android), with train/test splits and a harder long-horizon split, CUA-World-Long (one long task per software; often exceeding 500 interaction steps).

Key claims (expand)

Bullets summarized from the Gym-Anything wiki page.

Standardization & dual-agent reliability
  • Environment creation for complex software can be standardized so agents automate much of setup, debugging, and verification.
  • Creation plus audit agents improve reliability versus a single agent’s self-report; screenshots and logs expose actual state.
Economic grounding & task breadth
  • GDP-grounded selection yields benchmarks closer to economically meaningful work than short-horizon computer-use suites.
  • Propose-and-amplify separates expensive seeds from cheaper scaling.
Verification & generalization
  • Verification improves when a VLM grades against checklists built from privileged setup-script information.
  • Training on trajectories across many environments improves generalization to unseen software.

Gaps & limits (wiki)

  • GDP-grounded selection still leans on LLM-estimated category and software shares—opaque heuristics may shape “economic importance.”
  • Robustness of the verifier against agents optimizing the checklist rather than the workflow remains open.
  • The benchmark filters to sandboxable, self-hostable, GUI software; proprietary services, credentials, and physical hardware are out of scope for now.
